## Publicar gratuitamente com GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os arquivos `index.html`, `privacidade.html` e `.nojekyll`.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde a publicação e acesse o endereço exibido pelo GitHub Pages.

## Contato nesta versão
O site direciona o visitante ao WhatsApp ou e-mail. Não há formulário, banco de dados ou armazenamento próprio de contatos. A integração segura de formulário poderá ser adicionada posteriormente com um serviço de backend.

## Fotografia profissional
Se desejar inserir sua foto, crie a pasta `assets` e salve a imagem como `maria-eduarda.jpg`; depois, use esse caminho no atributo `src` da imagem em `index.html`.

## Privacidade e segurança
- Não coloque senhas, tokens ou chaves secretas no repositório.
- Não solicite nem receba relatos clínicos pelo primeiro contato.
- Revise o aviso de privacidade de acordo com os serviços efetivamente utilizados.
- O site publicado será público na internet, mesmo que o repositório tenha configurações de acesso diferentes.
